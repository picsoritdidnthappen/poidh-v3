# alternate frontends 👤👤👤 

### gnars bounties

"Gnars Bounties are challenges from the community: pay athletes in ETH to land the tricks, runs, and stunts the DAO wants to see filmed."

- https://www.gnars.com/community/bounties

### skatehive

"Complete challenges, upload proof, and earn rewards. Each bounty has a specific task — follow instructions and submit your video to get paid in ETH or HIVE."

- https://skatehive.app/bounties

### poidhz

"poidh has no on-chain deadline, so bounties state one in their description, or do not. This page reads every open bounty, pulls the date out of the text, and puts it on a calendar."

- https://poidhz.com/calendar

### poidh.borodutch.com

"an alternative frontend for the poidh protocol. same contracts, same bounties."

- https://poidh.borodutch.com/

### poidh.wei.limo (eth mainnet only)

"This page reads the bounty contract through a node you pick, and talks to nothing else. A claim’s picture is either in the claim itself — nothing to fetch, nobody to ask — or on a host the claimant chose, contacted only when you ask to see it.

- https://poidh.wei.limo/

### poidhverse

"The complete app—HTML, CSS and JavaScript—is stored in Ethereum contract bytecode. It reads current bounty state directly from POIDH contracts across Ethereum, Base, Arbitrum and Degen. POIDHverse has no backend, database or POIDH API dependency."

- https://poidhverse.wei.limo/

- https://farcaster.xyz/poidh-sentinel
